# Archived MAE experiments

These files document an earlier masked-autoencoder experiment but are not a runnable pipeline in the current repository.

`train_mae.py` and `eval_mae.py` depend on an unavailable `lsig_decode.py`. The best recorded CrossMAE run also used `model_crossmae.py` and `dataset_crossmae.py`, which are not present. The files and logs are retained as historical evidence; the missing implementation is not reconstructed here.
